# Limitaciones conocidas

No hay API oficial NotebookLM verificada en este entorno; el browser adapter real está implementado pero requiere sesión Google humana. La verificación de citas usa clasificación textual acotada. El challenger web devuelve candidatos externos separados, no autoridad canónica. El JSON store usa escritura atómica/backup, pero no es una base multi-proceso completa. Claude Desktop live aún no está certificado.
