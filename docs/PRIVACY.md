# Privacidad

Los documentos se consultan solo mediante el adaptador configurado. El modo por defecto es `LOCKED` para corpus; la evidencia externa, cuando se implemente el challenger, será una capa separada. No se envía contenido a servicios no configurados. El registro local contiene metadatos, fingerprints y cápsulas; revise/elimine `.data` según la política de su organización.
